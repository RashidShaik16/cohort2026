# Cursor Landing Page – CSS Assignment

This project is a recreation of the **Cursor landing page UI**, built as part of the cohort assignment.

The focus of this assignment is **layout accuracy, styling, spacing, and visual hierarchy using CSS**.  
No advanced interactions or JavaScript behavior were required at this stage.
And no ChatGPT is used anywhere except for the readme

- Focused on:

  - Typography
  - Color consistency
  - Spacing and alignment
  - Component styling
